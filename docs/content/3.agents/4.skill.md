---
title: The x18n skill
description: The agent skill that ships in the x18n package and teaches an agent the x18n workflows.
---

An agent skill is a markdown file that teaches a coding agent how to do a task. The `x18n` npm package ships one at `skills/x18n/SKILL.md`. The version of the skill always matches the version of the CLI that you install.

The skill tells the agent:

- to use x18n instead of editing locale files by hand,
- to check whether a key exists before it uses one,
- to keep placeholders, and to read the `--json` output and the exit codes,
- the loops of [Agent workflows](/agents/workflows): check, add a key, translate, review, clean up, rename and extract,
- how to page large outputs and how to pick a project in a monorepo.

## Install the skill

The skill is in `node_modules/x18n/skills/x18n/` after you install `x18n`. Agents do not read `node_modules`, so link the skill into the directory that your agent reads. [skills-npm](https://github.com/antfu/skills-npm) does this for every package that ships skills:

```sh
npm i -D skills-npm
npx skills-npm setup
```

`skills-npm setup` adds itself to the `prepare` script of `package.json`. After that, every install links the skills again, so the skill stays at the version of the installed CLI.

You can also copy `node_modules/x18n/skills/x18n/SKILL.md` into the skills directory of your agent by hand. Copy it again when you update x18n.

## Read it

The source of the skill is [`packages/cli/skills/x18n/SKILL.md`](https://github.com/antfu/x18n/blob/main/packages/cli/skills/x18n/SKILL.md). A test in the repository makes sure that every command and flag that the skill names exists in the CLI.
