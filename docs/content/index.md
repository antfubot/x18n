# x18n

x18n finds the locale files of your project, shows every key across locales, finds where keys are used, and keeps locale files healthy.

It is one engine with many surfaces: a CLI, a language server for any editor, a VS Code extension, and a UI that runs as a local server, a static report, or in the browser.

x18n is in early development. The plan lives in [`plans/`](https://github.com/antfu/x18n/tree/main/plans).
